零、小白导读（先看这里）

这份文档怎么用：你不需要一次读完。接线当天按这个顺序看就行——
① 第二节看电机怎么摆（机械）→ ② 第三节看 ESP32 插哪、哪些针不能碰 → ③ 第四节照着表一根一根接（每根线都写了"接哪个针"）→ ④ 第五节按顺序上电。

开始前必须记住的 3 条红线（违反会烧器件）

红线 1：INMP441 麦克风只能吃 3.3V。它板子上没有稳压电路，接 5V 立刻烧坏。
红线 2：电池（7.4V）绝不能直接碰 ESP32 的任何针脚。ESP32 只认 3.3V 和 5V（且只能接到专门的 5V 针）。
红线 3：面包板上只插"小电流"的线。电机、电池这种大电流的线全部在面包板外面直接连（第四节每张表都已注明）。

接线时最常用的 3 个操作

操作怎么做
夹顶母对母杜邦线的一端，夹在 ESP32 插进面包板后顶端还露在外面那一截针上。文档里写"J1-15 夹顶"，就是指"夹在 ESP32 左边那排针、从上往下数第 15 根针的顶头"。
电源轨面包板上下两条长排孔，旁边标了 + 和 −。+ 接 5V 正极，− 接公共地。左右两段是断开的，要用跳线把它们连起来（第五节第 2 步）。
跳线公对公的短导线，用来把两个孔连起来。文档里写"就近插孔"就是指用跳线接到最近的同一排孔里。

TB6612FNG电机驱动器。ESP32 的针脚力气小，带不动电机；由它来放大电流驱动电机，并接收 ESP32 的方向/转速指令。
INMP441本项目的麦克风（I²S 数字输出）。
MAX98357A本项目的小功放，把数字音频放大到能推动喇叭。

I²C两种设备间"一问一答"的数据总线，只用 2 根线（SDA 数据、SCL 时钟）。测距模块 VL53L0X 用它。
TCRT5000巡线传感器：发红外光看反射，黑色吸光/白色反光，输出"黑/白"电平，用来让机器狗沿线走。
VL53L0X激光测距模块，量前方障碍物有多远（几毫米到 2 米）。
ADC把电压读数变成数字的部件。ESP32 用它读电池电压。
分压（电阻分压）用两个电阻把高电压按比例降低。7.4V 电池信号必须先降到 3V 以下才能进 ESP32。
MP1584降压模块，把电池 7.4V 降到 5V 给全机用。买回来先调到 5.0V 再接负载。
LDO低压差稳压器。ESP32 板子上就有一个，把 5V 降到 3.3V 给自己和麦克风用。
2S 电池两块锂电池串联：满电 8.4V、标称 7.4V、放到 6.4V 就该充电。2S 是航模圈的说法（S=series 串联）。
BMS电池保护板，防过充、过放、短路。买电池时选带 BMS 的。
strapping 脚启动时有特殊含义的针脚（本板上是 GPIO0/3/45/46），乱接会导致开不了机。文档已帮你避开。
SPI flash / PSRAMESP32 模组内部的存储芯片，占用了 GPIO 26–37 这些针，不能再用作普通针脚。
N16R8 / WROOM-1你买的模组型号：16MB flash + 8MB PSRAM。买错成 N8R2 跑不了语音固件。
USB D+/D−（GPIO19/20）ESP32 自己那路 USB 的数据线，被芯片内部占用，不能接外设。
上拉把一个信号默认"托"在高电平的电阻。按键模块多数自带或由固件启用。
双绞把电机的两根线绞在一起，减少对旁边信号线的干扰。
肖特基二极管低压降、只允许单向导电的二极管。此处用途：防止 USB 5V 和电池 5V 互相倒灌。
万向轮 / 滑脚四足仿生前部的两个"前腿"支撑件，可选方案之一。
夹顶针位本文档特有的说法：母对母杜邦线该夹的 ESP32 针脚位置（含排针号与 GPIO 号）。
SSD13060.96 寸小 OLED 屏的驱动芯片，128×64 个白点，自发光、不用背光。我们买的是 7 针 SPI 版（官方教程多用 4 针 I²C 版）。
SPI一种"高速串行收发"总线：一根时钟 + 一根数据。比 I²C 快，适合刷屏。我们用它驱屏幕。
MOSI / SCLKSPI 的两个方向：SCLK=时钟（谁在驱动节奏），MOSI=主发从收的数据线。
DC屏幕的"数据/命令"开关脚：高电平=传画面数据，低电平=传控制命令。
RES / RST屏幕的复位脚，上电时被拉低一下就重启屏幕。
CS（片选）SPI 上"点名"用的脚。只有一个设备时把它一直接地，等于永久选中。

四、引脚级接线总表

新手怎么看第四节的表：每张表三列意思都一样——第一列= 器件上的这个脚（照器件丝印找）；第二列= 要接到哪里（GPIO 或电源轨）；第三列= 具体怎么接（夹 ESP32 哪个针的顶，或插面包板哪一带）。接一根线就在纸上打个勾，全部打完勾再上电（第五节）。
接线方法（400 点板的关键技巧）：ESP32 直插面包板取电与固定；模块信号用母对母杜邦线夹在 ESP32 引脚顶部（引脚是长针，插入后顶端仍外露），另一端插模块引脚孔。这样避免"一个孔插两根线"，也避免反复插拔 ESP32。表中"夹顶针位"即杜邦线该夹的 ESP32 针。

四之二、OLED 屏幕接线（v4 新增）

4.5.1 为什么 CS 脚可以直接接 GND

本项目可用 GPIO 只剩 4 个（GPIO1/GPIO2/GPIO46/GPIO48），而 7 针 SPI 屏按老规矩要占 5 个信号脚（SCLK/MOSI/DC/RES/CS）。SPI 总线上只有一个从设备时，片选 CS 可以一直接地——反正只跟它说话，不需要"点名"。这样就省出一个针脚，4 个 GPIO 刚好够用。

顺带的好处：省下的引脚以后还能给第二个 SPI 设备用；且 CS 固定接地，避免了"某个 GPIO 没初始化导致总线被误片选"的经典坑。

4.5.3 屏幕能显示什么（固件已支持）

  • 开机：Wi-Fi 连接状态 / 配网提示
  • 对话：识别中、思考中、回答内容与表情
  • 设置页里的提示与通知（配网、音量等）
固件依据：屏幕驱动用 ESP-IDF 的 esp_lcd_new_panel_ssd1306 + xiaozhi 的 OledDisplay（和官方面包板同一套代码，只把接口从 I²C 换成 SPI）。若屏幕初始化失败，固件自动退回"无屏模式"继续跑语音，不会变砖。

五、400 点板施工顺序与上电前检查

  1. 先规划分区再插线：ESP32 靠左插（rows a/j，列 1–22，USB 朝右）→ 音频区（d/e 行，列 1–12）→ 传感器区（f/g 行）→ 电源轨。
  2. 轨先桥接：上下 4 条轨左右两段用跳线连通，不通电量通断。
  3. 只接 MP1584 与电源轨，输出调到 5.00V；摸 MP1584 不烫。
  4. 插音频区，用母对母线从 ESP32 夹顶；核对 4/5/6/7/15/16 六根 GPIO。
  5. 插传感器区（巡线/测距/按键/分压），注意 AO 悬空。
  6. TB6612 装在板外，6 根信号母对母线夹顶；VM/VCC/GND/AO/BO 全部直连。
  7. 上电前断电检查：短路测量、共地、分压电压、域分离（功率线未插孔）。
  8. 分步上电：轨 → 主控（USB，看日志与"控制服务已启动"）→ 音频 → 电机（轮悬空）。
400 点板特有的三个新风险：① ESP32 板身会遮住它上面/下面 1–2 行孔，模块务必留出 d/e、f/g 行再插，别硬挤；② 400 点板薄、触点弹力弱，大电流过一次就可能永久松动，功率线坚决外接；③ 母对母线夹顶时别夹到相邻针，插错一根程序看似能跑、行为全乱。

六、v2 → v3 差异对照

项v2（830 点）v3（400 点 + 四足）
面包板规格按 830 点规划（63 列）400 点（30 列），ESP32 占 22 列，模块改插 d/e/f/g 行

电机布置未涉及机械四足仿生：后轮驱动 + 前支撑脚；轴距/轮距/重心/前脚高度量化要求
TB6612板外，6 信号维持板外；明确 6 根信号各自夹顶针位

后续若换 830 点或上结构件，仍可回到 v2/v1 的域分离原则；本文第四节的引脚对应关系不变，只是插孔位置不同。

二、电源设计

2.1 电源树

电压轨来源去向与限额
7.4V（VBAT）2S 电池（直接）只进 MP1584 输入端。不进任何逻辑/信号
5V 轨MP1584 输出（调压到 5.0V，务必先调后接负载）TB6612 的 VM 和 VCC、主控 5V 脚、MAX98357A VDD、TCRT5000、VL53L0X（需其板上 LDO 或确认输入范围）
3.3VESP32-S3 板载 LDO（USB 或 5V 脚供电时产生）仅给 ADC 分压参考、I²C 上拉。整机 3.3V 负载很小
关键决定：电机 VM 用 5V 而不是 7.4V。底盘 TT 电机通常是 3–6V，直接喂 7.4V 会过热、抖动并可能烧电机。所以电机也从 5V 轨取电；MP1584 标称 3A，足够两台电机轻载 + 音频。

2.2 电流预算（估算，实测为准）

负载典型电流备注
ESP32-S3（Wi-Fi 发射峰值）~350 mA峰值出现在 Wi-Fi 激活与上传音频
MAX98357A + 喇叭（中等音量）~200 mA音量越大越接近上限；狗叫短时不超
2×TT 电机（平地稳定行驶）各 ~150–250 mA堵转时可到 1A+，靠 TB6612 限流与固件限速兜底
巡线传感器 ×5各 ~10 mA红外管常亮
VL53L0X~20–40 mA测距发射时偏高
合计（典型）≈1.0–1.5 AMP1584 3A 留有余量；电池 2Ah 理论续航约 1.3h，实际以整机实测为准
不要用面包板走电机电流。电机 VM/AO1/AO2/BO1/BO2 必须焊接或用杜邦线压接+热缩管固定，面包板触点会发热甚至熔化。电池主线也用足够的线径（≥20AWG）。

器件接到说明

四、上电前检查清单（逐项打勾，不打勾不通电）

4.1 断电状态下的检查（电池不接、USB 不接）

  • 共地检查：万用表通断档，确认所有模块 GND 与电池负极/主控 GND 导通（同一等电位点）。
  • 目视复查：对照第三节点表，一根一根核对，重点确认没有把 5V 接到 INMP441 VCC（3.3V 器件）。
  • VBAT 悬空确认：GPIO8 分压电阻下端接 GND、上端接电池正极，中间抽头进 GPIO8；分压电阻先焊好再测电压，后接 GPIO。
  • 短路检测：万用表二极管档测 5V 轨对 GND、VBAT 对 GND，不得出现 0Ω 导通（蜂鸣即为短路，未排除不得上电）。
  • MP1584 调压：先只给 MP1584 上电（电池正负极），调到 5.00V 再接负载；可调款别留在 7V 以上。
  • 极性/防呆：XT60 或插头核定电源极性标志；母线加开关（不用时物理断开）。
  • 机械防护：电机线、喇叭线打结固定留余量，避免转动卷线；金属狗壳与地之间留间距。

4.2 分步上电顺序（先空载，后带载）

  1. 第一步：断开电机线（TB6612 的 AO1/AO2、BO1/BO2），USB 不接主控。给电池上电，测 5V 轨是否为 5.0V、VBAT 是否为 7.4V 左右。
  2. 第二步：接主控（USB 或 5V 脚），串口监视器看启动日志，确认：Connected to WiFi → AiDogControl: 局域网控制服务已启动。
  3. 第三步：接音频（麦克风、功放、喇叭），用 App 看电量/状态页面，说话看唤醒与 TTS 播放。
  4. 第四步：最后接电机线。上盖前先让轮子悬空，运行模式和急停测试，看日志中的模式切换与停止。
  5. 第五步：整机装回，跑一遍"巡逻→急停→断线恢复"，确认无意外停机。
上电前最危险的 4 个点： ① 5V 进 3.3V 器件（INMP441）会直接烧毁； ② 电机电流走面包板会过热起火； ③ VBAT 不衰减直连 GPIO8 会击穿 ADC； ④ 电机与音频共地回流不良会烧坏 I²S/ADC（本方案已要求单点共地，务必焊接）。

五、接线后常见故障速查

现象最可能原因处理
整机无反应，无日志GND 未共地 / 5V 轨没输出 / USB 线是电源线非数据线先量 5V 轨；换数据线；查共地
Wi-Fi 连不上2.4GHz 未启用 / 5G-only 路由器 / 密码错确认路由 2.4G；重配网；看串口日志
能连网但控制服务没起固件未更新到含控制服务的版本（提交 deab432）重新烧录当前 xiaozhi.bin

有声音但电流声大喇叭线贴着电机线 / 共地回流走面包板音频线与电机线分开走；确认单点共地
App 显示离线IP 填错 / 手机与设备不在同一网段 / 设备 DHCP 换了 IP串口打印或路由器客户端列表查新 IP；后续可加 mDNS

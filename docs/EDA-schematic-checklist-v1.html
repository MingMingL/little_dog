3. 连完自检（必须全绿才转 PCB）

  • 「设计 → 检查 DRC」：未连接引脚 = 0、重复位号 = 0、单端网络 = 0。
  • 网络数应 = 36；逐个点网络看高亮成员数是否与上表"成员"列一致（不一致就是漏连/多连）。
  • 把原理图与 docs/PCB网表-v2.csv 并排：CSV 的 108 行应能一一对上。
  • GND 网络成员最多（17 个），最容易漏；点 GND 高亮，数一遍。
  • 最后：设计 → 更新/转换到 PCB，飞线数应为 108 条（每条 pin-net 一根）。

4. 这 8 个地方最容易点错

#易错点为什么 / 怎么点
1GPIO9 不接任何东西模式按键已从 PCB 与面包板移除，网络表里没有 GPIO9 网——EDA 里别手痒补上。
25V 必须经 D1(SS34)MP1584EN 的 OUT+ 不能直连开发板 5V 脚；中间串 SS34，否则插 USB 时倒灌。
3SW1 在 FS5080E 的 IN 之前顺序是 5V → SW1 → U3.IN。接反等于开关失效，电池会自己给自己充电。
4电机 VM 走 7V4 不是 5VU4.VM 接 7V4；接 5V 会让 MP1584EN 峰值 3.67A 超载。
5MAX98357A：GAIN→GND、SD→VIN模块上这两根是模块内短接的等效；VIN 是 5V。
6INMP441：L/R→GND选左声道；悬空会出双声道叠加的噪声。
7OLED：CS/SA0→GND，Vin 与 3v3 都→3V3CS 固定片选、SA0 固定地址；Vin/3v3 同时给 3V3（模块内部 LDO 直通）。
8开发板 3V3 是输出J1-32/33 是板载 LDO 输出，往传感器送电；别当成需要外部供电的输入。

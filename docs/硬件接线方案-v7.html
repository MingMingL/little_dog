开始前必须记住的 3 条红线（违反会烧器件）

红线 1：INMP441 麦克风和 OLED 屏幕只能吃 3.3V。它们板子上没有稳压电路，接 5V 立刻烧坏。
红线 2：电池（7.4V）绝不能直接碰 ESP32 的任何针脚。ESP32 只认 3.3V 和 5V（且只能接到专门的 5V 针）。
红线 3：面包板上只插"小电流"的线。电机电流、电池主线、ESP32 主供电全部在面包板外面直连（第四节每张表都已注明）。

面包板连通规则（v7 勘误，接线前必读）

v3–v6 写错了一条规则，v7 纠正：面包板主区不是"横着 5 个孔相通"，而是竖着相通——同一列、同一半区的 5 个孔相通。例如第 12 列：a12/b12/c12/d12/e12 五孔相通，f12/g12/h12/i12/j12 五孔相通，而 e12 与 f12 被中间凹槽隔开、不相通；a12 与 a13（相邻列）也不相通。
这对你只有一个好处：每个模块的相邻针脚天然各占一列、互不短路，模块可以直接插板；信号线用公对公跳线"列对列"连接即可。自检方法：空板上用万用表蜂鸣档量任意两孔——同一列同半区响，横着相邻不响（教程第 0 步会带你做）。

二、小白逐级上电验证教程（v7 新增 · 防烧主线）

这一节是"手把手"章节：每一步只做一件事，做完用万用表验证，正常了才往下走。90% 的"接线烧板"都死于两件事：没量电压就插 3.3V 器件、大电流走了面包板。按本节走，这两件事都被卡死在流程里。

2.2 万用表三个用法（5 分钟学会）

万用表两条保命纪律：① 测电压时表笔绝对不能改插"电流孔"——多数表电流孔和 COM 孔是分开的，电压档时表笔必须插回 VΩ 孔，否则等于把电源短路，会打火；② 不知道量多少就先选最大量程（20V），再往下调。

2.3 电压怎么调（把 5V 调到 5.00V）

先建立概念：本机所有"5V"都来自同一个源头，你只需要在总入口把它调准一次。硬件已到齐，供电路径回到主方案：2S 电池（7.4V）→ MP1584 降压 → 5.00V → 面包板轨 + 各模块 + 电机。

场景要不要调怎么做
电池 + MP1584（现状·主方案）必须自己调见下方"六步法"：7.4V 电池 → 调到 5.00V。这是整机唯一需要调压的地方，其他模块的电压都是它分配的（5V 走轨、3.3V 由 ESP32 板载 LDO 从 5V 变出来）。
可调电源（电压电流双旋钮，如有）先调压、再限流电压旋钮拧到 5.00V，电流旋钮拧到最小，然后见 2.4 节限流。
USB 线不再用于供电v5/v6 的"USB 临时供电（电池未到）"方案已废除——USB 只保留一个用途：烧录固件（见教程第 3 步），烧完就拔，整机运行一律不插 USB 供电线。
MP1584 调 5.00V 六步法：
① 断电，把 MP1584 的 IN+/IN− 接电池（7.4V，经开关），OUT+/OUT− 先只接万用表（红笔 OUT+，黑笔 OUT−），不接任何负载；
② 上电，表拨直流 20V 档，先确认 OUT 读数是个小零头（零点几伏，随电位器位置而变）；
③ 小螺丝刀插进模块侧面电位器，每次只拧一点点，拧完停 2 秒看读数（顺时针/逆时针哪边升，各模块不同，试一次就记住）；
④ 拧到 5.00V（4.95–5.05 都算合格）；
⑤ 接上全部负载，再量一次 OUT：带载后只要还 ≥4.85V 就合格（掉太多说明线太细或模块功率不够）；
⑥ 搞定后给电位器点一滴指甲油/热熔胶封住，防止震动跑偏。
"限制电压"到底限制的是什么：你真正要防的是"高压进低压器件"——3.3V 的 INMP441 和 OLED 接 5V 就烧。所以规则只有一条：全机的 5V 只有一个出口（MP1584 输出/5V 轨），3.3V 只有一个出口（ESP32 的 3V3 针），插任何器件前先量它那个孔的电压对不对（教程第 3 步）。

2.4 电流怎么调、怎么限（本教程的核心安全课）

先说一个最常见的误解：电流不是"你想要多少就有多少"，而是"负载要多少、电源最多能给多少"里的小值。所以安全电流管理其实就三句话：① 电源供得起（电压不塌）② 电线/面包板扛得住（不发热）③ 异常时看得见（电压跌落、发烫、重启）。

器件典型电流从哪取电
ESP32-S3（Wi-Fi 峰值）空闲 80–160mA / 峰值 ~350mAMP1584 直连 5V 针（J1-21），不走轨
SH1106 OLED 屏幕~20mA（3.3V）ESP32 3V3 针
INMP441 麦克风~5mA（3.3V）ESP32 3V3 针

2WD 电机 ×2空载 60–150mA/台；堵转 1A+/台MP1584 直连 TB6612，绝不过板
面包板轨的硬上限：一条电源轨别超过 500mA（830 点和 400 点的触点规格一样，没有"830 点更能扛"这回事）。所以上表的取电分工是刻意设计的：ESP32 和电机的峰值电流都从 MP1584 直连，轨上只留功放+传感器共 ~300mA。

限流的三种手段（按你手上的装备选）

  1. 有可调电源/带恒流（CC）的模块（最佳）：① 先把电压设成 5.00V；② 电流旋钮从最小慢慢拧大，同时盯着电压表；③ 拧到"负载全接上但电压不再往下掉"的位置，再退回 20% 余量，这就是你的电流上限。好处：真要短路，电源自动限流，不会打火。
  2. 只有 MP1584（限压不限流）：限流靠"选电源 + 分路上电 + 死盯电压"。任一步出现"5V 读数掉 0.1V 以上"或"器件发烫、主控重启"，立即断电，那一级就是超限点，拆了重判。
  3. 固件软限流（最后一道防线）：App 遥控把速度拉到 30% 以下再试；固件里 remote 模式默认就是低速起步。堵转（轮子被按住不转）时电流翻几倍，是电池降压模块和 TB6612 的最大杀手——拿在手上玩时，绝不让轮子被捏停超过 1 秒。
电池预算（现行主方案）：2S 电池标称 7.4V，选 2000mAh 以上带 BMS 的。MP1584 按 5V×1.5A 选（留够余量）。全机逻辑部分 ~0.5A、双电机中速 ~0.8A，合计峰值 ~1.3A，MP1584 会有点发热属正常，烫手才异常。

2.5 十步上电验证（照做，每步 3 分钟）

原则：先断电把所有线接好 → 但每加一级负载，都先"量电压"再"看现象"。表里"期待值"之外的任何读数，先停手、别继续往下接。

第 0 步：断电体检（一次学会，以后每次接线前都做）

做什么所有线按第四/五节接好，电源全不插（电池不接、USB 不插）。
量什么蜂鸣档：① 5V 轨 对 GND 轨：不响；② ESP32 3V3 针 对 GND 针：不响；③ 随手抽查 5 个孔（同列同半区应响、横邻不响）。
期待值全部符合"该通的不该通的"判据；目检无歪针、无散丝搭邻列。
异常持续蜂鸣 = 有短路。分段排查：拔掉轨外来线 → 还响就逐模块拔，直到不响，最后拔掉的那个就是祸根。

第 1 步：空板上电（只接 MP1584，什么都不插）

做什么电池经开关接 MP1584，MP1584 输出先只接 5V 轨和 GND 轨；ESP32 和所有模块都还没插。
量什么直流电压档量 5V 轨；USB 电流表串在电池回路看总电流。
期待值轨电压 = 4.95–5.05V；总电流 ≈ 0mA；摸 MP1584 不烫。
异常电压超 5.1V → 回 2.3 重调电位器；有电流且发热 → 轨上有隐藏短路，回第 0 步。

第 2 步：插 ESP32（全机第一次“活过来”）

做什么MP1584 直连线 → ESP32 5V 针（J1-21）；断电插好，再上电。先只接它一个。
量什么① J1-21 电压；② 3V3 针（J1-1）电压；③ 总电流。
期待值5V 针 4.7–5.0V（板载保护二极管会掉 0.2V 左右，正常）；3V3 针 3.2–3.4V；电流 80–160mA；串口有启动日志。
异常电流超 300mA 或电压掉到 4.5V 以下 → 立刻断电，多半是 5V/GND 接反或 3.3V 器件已误插；主控烫手 → 同判。

第 3 步：先烧固件，再接一根线（USB 只在这里出现）

做什么断开电池，USB 线插 ESP32 自己的口，按 docs/固件开发环境.md 烧录。烧完拔 USB，恢复电池供电。
量什么烧录成功后日志出现 SH1106 OLED 已就绪（没插屏时会自动回退无屏模式，不报错即可）、局域网控制服务已启动。
期待值烧录 100%、重启后日志正常。这一步不碰面包板，不存在烧机风险，却能在接线前排除固件问题。
异常烧不过 → USB 线换成数据线；先解决固件再接线，不要"边接边试"。

第 4 步：先量“模块孔位电压”，再插 OLED（全机第一个外设）

做什么OLED 的电源线先接好但模块本身先不插：3.3V 线已顶到它的 VCC 孔、GND 到 GND 孔。上电量这两个孔。
量什么OLED 的 VCC 孔（对 GND 孔）电压。
期待值3.2–3.4V。是 5V 就不插，先查跳线是不是从 5V 轨来的。
然后断电，插上 OLED，插 4 根信号线（母对母夹顶），上电 → 日志打印 SH1106 OLED 已就绪 + 屏幕亮。黑屏先查 CS 是否接地。

第 5 步：INMP441 麦克风（第二个 3.3V 器件）

做什么同第 4 步套路：先接电源不插模块，量 VCC 孔 = 3.3V 确认后，断电插模块、插 3 根信号线，上电。
量什么总电流较第 2 步只应多 ~5mA；对着麦克风说话，看 OLED 上是否出现"聆听/识别中"。
异常无声且模块发烫 → 立即断电，VCC 多半接了 5V，已烧，换模块。

第 6 步：MAX98357A 功放 + 喇叭

做什么先量 VDD 孔 = 5V（这次是 5V，别搞反），断电插模块和 3 根信号线；喇叭最后接。
量什么播放 TTS 时总电流增量（音量 50% 时 +100mA 上下正常）；喇叭应有声。
异常功放任一秒就烫 → 拔喇叭断电查接线；声音断续 → 5V 轨被拖垮（看第 1/2 步残余电流记录）。

第 7 步：传感器区（巡线 ×5 + VL53L0X）

做什么每颗先量 VCC 孔 = 5V，再插；AO 脚一律悬空不接。
量什么总电流合计应 ~+100mA；用手挡巡线探头，串口/OLED 状态应有变化；VL53L0X 前方放只手，距离读数变化。
异常某颗永远一个读数 → DO 跳线列号接错（对照第五节表核对列号）。

第 8 步：TB6612 + 电机（最后一级，轮子悬空）

做什么TB6612 放板外：6 根信号母对母夹顶；VM/VCC/GND 从 MP1584 直连，不碰面包板。上电前确认轮子离地。
量什么低速点一下 remote 模式方向键：量 ESP32 5V 针电压（应稳住 4.8V+）、总电流（单台中速 +80–150mA）。
期待值轮子转、电压不塌、TB6612 只是微温。
异常电机一转主控就重启 = 电流不够/线太细 → 降速或换 20AWG 直连线；TB6612 烫手 → 查 VM 是不是没接/接错。

第 9 步：全负载拷机 5 分钟 + 记录归档

做什么巡逻模式跑 5 分钟（电机 + 语音 + 屏幕同时开）。
量什么每 1 分钟记一次总电流和 5V 轨电压；结束时摸 MP1584 / TB6612 / 各跳线。
期待值电压全程 ≥4.85V；所有东西"温热正常、烫手异常"；电池电压从 8.4V 缓慢下降。
然后拍照存档接线 + 读数，以后改线前后各对比一次。

三、一套 2WD 底盘的布置（含左右两台电机）：仿四足

3.1 姿态方案

先澄清防误读：本文所说的"两个 2WD 电机"，指的是一套 2WD 底盘里自带的左轮电机 + 右轮电机（各驱动一个后轮），不是两套底盘——采购量就是 1 套（见 PRD 清单）。之所以一台底盘里要装两台电机：一台电机只能直行/倒车，转弯必须靠左右轮转速差（差速转向），这也是巡线时实时左右修正的唯一廉价实现。到货验收：数一数应有 2 台电机、2 只驱动轮、2 只万向轮（部分套件不含，需另配）。

连接走法
2S 电池 ↔ 开关 ↔ MP1584 输入（7.4V）板外直连，禁止上面板；先按 2.3 节把输出调到 5.00V

MP1584 输出 → TB6612 VM / VCC≥20AWG 直连线，绕过面包板
MP1584 输出 +5V → 下轨 +（两段都桥接）一根线接轨端孔，供功放/传感器
MP1584 负极 → 上轨 −（一根汇流线）星形接地点：电池负极、面板地、TB6612 地在此汇合
3.3V 分配：J1-1/2 → INMP441 VCC、OLED VCC两根跳线（列 6 → 列 31、列 6 → 列 54）；合计 <30mA，安全
上电前最后一眼：全部接完后，先合开关前的 30 秒里检查：① MP1584 输出量一次 5.00V（教程第 1 步）；② TB6612 的 VM 线确认插在 MP1584 输出上、没有哪根误插到面包板轨；③ 电机线正确对接、没有互碰。然后按第二节十步流程走。

5.5 OLED 屏幕接线（1.3 寸 SH1106/SSD1106 128×64，7 针 SPI，上排 53–59 列）

先确认你这块屏的尺寸：1.3 寸 = SH1106（固件已切到该驱动，日志打印 SH1106 OLED 已就绪）；0.96 寸 = SSD1306。买错或标题看错尺寸，只要改 config.h 里一行开关（DISPLAY_DRIVER_SH1106）重编译就能救，不用改线。
屏幕引脚（照模块丝印）接到830 点接法新手提示
GNDGND 轨插第 53 列；跳线 → 上轨 −负极，必须接
VCC3.3V插第 54 列；跳线 54 → 列 6（3V3）接 3.3V，不是 5V——多数 1.3 寸模块无稳压，5V 会烧
CLK / SCL / D0GPIO1插第 55 列；母对母夹 J3-4 针顶时钟线
DIN / MOSI / D1GPIO2插第 56 列；母对母夹 J3-5 针顶数据线，别和 CLK 接反
DCGPIO46插第 57 列；母对母夹 J1-14 针顶告诉屏幕"这字节是命令还是画面数据"
RES / RSTGPIO48插第 58 列；母对母夹 J3-16 针顶复位线
CS直接接 GND插第 59 列；跳线 → 上轨 −不占 GPIO；千万别接 VCC（错接=全黑无显示）
为什么 CS 可以直接接 GND：SPI 总线上只有一个从设备时，片选 CS 可以一直接地——反正只跟它说话，不需要"点名"。这样省出一个针脚：本机只剩 4 个 GPIO（1/2/46/48），刚好够 CLK/DIN/DC/RES 四根信号。顺带好处：省下的引脚以后能给第二个 SPI 设备；且 CS 固定接地，避免"某个 GPIO 没初始化导致总线被误片选"的经典坑。
屏幕能显示什么（固件已支持）：开机 Wi-Fi 连接状态/配网提示、对话中的识别/思考/回答内容与表情、设置页提示。屏幕初始化失败时固件自动退回"无屏模式"继续跑语音，不会变砖。

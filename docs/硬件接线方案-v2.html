二、核心设计：功率域 / 逻辑域两域分离

面包板的电源轨每段实测只能稳定承担 500mA 上下，且触点压降随电流快速上升。因此本方案把电流按大小分成两个域：

域包含的连接实施方式
功率域
（大电流）		电池 ↔ MP1584 输入；MP1584 输出 ↔ ESP32 的 5V 脚；MP1584 输出 ↔ TB6612 的 VM 与 VCC；TB6612 AO1/AO2/BO1/BO2 ↔ 电机全部点对点直连，一根都不进面包板孔。线径 ≥20AWG，端子焊接或压接后热缩管固定
逻辑域
（小电流）		麦克风、功放、巡线×5、测距、按键、分压采样等 <350mA 的供电与全部信号线走面包板，插 22–26AWG 单芯线（多股线上锡后再插）
面包板的三条红线：① 电机 VM/AO/BO 与电池主线绝不上面包板——触点会发烫、熔化、失效；② ESP32 的 5V 脚也直连 MP1584 输出（Wi-Fi 峰值 350mA 不占面包板预算）；③ 面包板 GND 轨与功率域只用一根汇流线接到 MP1584 负极端子（星形接地）。

三、面包板俯视图（830 点布局）

布局原则：ESP32 居中，音频靠左，传感器靠右，TB6612 放面包板外右侧（它的功率脚不上面板，只插 6 根信号脚）。上下电源轨桥接左右两段。

四、面包板施工规则

4.1 电源轨分配（解决"轨只能扛 500mA"）

轨 / 连接供电对象预估电流
下轨 +5V（左段）MAX98357A VDD、VL53L0X、TCRT5000×5（INMP441 用 3V3 脚单独供电，不占此轨）≈ 250–290 mA
上轨 GND（左段）上述全部模块 GND + 面包板上拉/分压下端回路，同电流量
轨右段（桥接）仅传感器区延伸 + 空闲冗余，不放大电流负载≈ 60 mA
ESP32 5V 脚直连 MP1584 输出（不算面包板预算）峰值 ~350 mA
TB6612 VM/VCC直连 MP1584 输出（不算面包板预算）电机峰值 1–2 A
3.3V 提示：INMP441 的 VCC 已在 v1 中标注为 3.3V 器件。面包板上 3.3V 从 ESP32 的 3V3 脚单独跳线到麦克风区，不要从 5V 轨取；3V3 脚只给麦克风（<20mA），安全。

4.2 插线规则（面包板特有）

  • 单芯线优先；多股线必须预先上锡成一股再插，否则氧化后接触不良，故障极难查。
  • 一个孔只插一根线。需要并线时用"相邻两孔 + 一根跳线桥接"，不要硬塞两根。
  • 电源轨左右两段必须用跳线桥接（出厂是断开的），否则远离电源那侧模块没电。
  • 插线前先核对同一列导通、相邻列不导通（可用万用表通断档在空板上验证一次，建立信心）。
  • 信号线走面板内侧区域，电机/电池线走面板外空间并绑扎，两者分层不交叉。
  • 音频线（麦克风/功放）与 TB6612 过来的 6 根信号线分区布置，中间用 ESP32 占位自然隔开。

4.3 焊接/压接要求（功率域）

  • MP1584 输入/输出端子：线头塘锡或压接端子，M3 螺丝紧固，套热缩管。
  • TB6612 的 VM/VCC/GND/AO/BO：尽量焊在端子或直接焊到电机线，不允许插面包板孔。
  • 电机两端各並联 100nF 陶瓷电容；电机线双绞。
  • 电池负极与 MP1584 负极就是本机的唯一汇流点；面包板 GND 轨用一根 20AWG 线接到这里。

五、上电前检查清单（面包板版）

5.1 断电检查

  • 轨桥接：上下电源轨的左右两段都已用跳线连通（不通电，用通断档量）。
  • 域分离复查：确认 VM、电机四线、电池主线、ESP32 5V 脚——没有一根插在面包板孔上。
  • 共地：面板 GND 轨 ↔ MP1584 负极只有一根汇流线；GND 轨上各模块地都导通。
  • 3.3V/5V 分区：INMP441 VCC 接的是 ESP32 3V3 脚，不是 5V 轨。
  • 短路检测：电池不接、USB 不接，量 5V 轨对 GND、VBAT 对 GND，不得 0Ω 导通。
  • MP1584 调压：只给 MP1584 上电，输出调 5.00V 再接任何负载。
  • 分压电阻：100k/47k 已插牢，中间抽头即将进 GPIO8；先量抽头电压（应 <3V）。
  • ESP32 插入确认：两排针都插到底，每脚与相邻列不短路（抽查若干脚通断）。
  • 插线质量：无单孔双线、无多股线散丝、无线皮被夹破。

5.2 分步上电

  1. 第一步：电机线保持断开。电池上电 → 量 5V 轨 = 5.0V、VBAT ≈ 7.4V；用手摸 MP1584/TB6612 不发热。
  2. 第二步：USB 插主控看日志：应出现 Wi-Fi 连接 → AiDogControl: 局域网控制服务已启动。
  3. 第三步：App 配 IP，看状态页电量/故障；说话测试麦克风与 TTS。
  4. 第四步：接上电机线（轮子悬空），点巡逻/急停，观察模式切换与停止。
  5. 第五步：整机固定后复查一次所有功率域端子温度（空转 2 分钟）。
面包板场景下新增的三个高危点：① 有人图省事把 VM 插上 5V 轨——一次重载就可能让轨熔化，本方案已用域分离杜绝；② 轨左右段忘桥接——"半边有电半边没有"的灵异故障；③ 多股线散丝搭到相邻列——随机短路，查半天。

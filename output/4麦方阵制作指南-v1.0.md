## 〇、30 秒导读

成品买不到就自己焊：**4 只 INMP441 模块 + 一块 5×7cm 洞洞板**，约 ¥30–45，1 小时工作量。核心就三句话：**电源和时钟 4 麦共享、数据线各走各的、4 个麦克风朝向同一个方向摆成正方形**。焊完后按 §6 上电检查，按 §7 减振安装。

---

## 1. 为什么买不到现成的（先说清楚，别浪费时间搜）

| 市售类型 | 为什么不适合 |
|---|---|
| ReSpeaker 4 麦阵列（树莓派用） | 模拟麦克风 + WM8960 编解码芯片，输出给 Linux 板；ESP32 直接接不了，还要额外 ADC |
| ESP32-S3-Korvo 类开发板 | 只带 2 麦，且麦在板上一侧，摆不成方阵 |
| 智能音箱 6+1 / 8 麦环形阵 | 多为模拟麦 + 多通道 ADC（如 ES7210），接口和时序都为 Linux 方案设计；环形/线形也不匹配我们的方阵设计 |
| 单只 INMP441 模块 | **这才是我们要的**——买 4 只自己拼 |

**结论**：I²S 数字 4 麦方阵没有匹配 ESP32 的成熟成品，DIY 是正解，也最便宜。

## 3. 阵列几何（DOA 的输入，摆错全盘皆输）

- **形状**：正方形，边长 **4–5cm**（建议 4.5cm）。不要排成一排（线阵有前后 180° 模糊，分不清人在狗前还是狗后）。
- **朝向**：4 只麦克风的**收音孔全部朝向同一方向**（朝上或朝前——INMP441 模块的进声孔在模块正面/贴麦那面，别被洞洞板挡住）。
- **共面**：4 只必须在同一平面，误差 1–2mm 内；用同一块板子固定就能保证。
- **水平放置**：阵列平面水平（平放）→ DOA 输出就是水平面内的 0–360° 方位角。
- **坐标（固件要用）**：以阵列中心为原点，边长 d=4.5cm，则 4 麦坐标约为 (±2.25cm, ±2.25cm)。`esp_apa_doa` 组件有现成宏 `ESP_APA_DOA_MIC_POS_SQUARE(0.045)`（参数为边长，单位米），方阵直接用它。
- **安装朝向校准**：让阵列坐标系的 **+Y（0°）对准机器狗正前方**，这样 DOA 输出的角度就是"声源在狗身哪个方向"，固件不用再换算。

## 4. 接线（核心，一张表照做）

| INMP441 模块引脚 | 接法 |
|---|---|
| VDD | **全部**接 3.3V（INMP441 只能 3.3V，接 5V 立即烧毁） |
| GND | **全部**接共地（**星型接法**：4 个麦的 GND 各拉一根线，回到板上同一个"总地"点——像自行车辐条汇到车轴；别一个接一个串着接。为什么，见下面的"新手名词"框） |
| SCK（位时钟） | **全部并联**后接一根线 → ESP32 **GPIO5** |
| WS（字选择） | **全部并联**后接一根线 → ESP32 **GPIO4** |
| SD（数据） | **每只各走各的**，4 根独立线 → GPIO **6 / 38 / 39 / 40** |
| L/R（声道选择） | **全部接 GND**（4 只都选左声道） |

对应最终实施方案 §3.2 引脚表：GPIO6 是原有麦克风的数据脚，GPIO38/39/40 是巡线改 PCF8574 后释放出来的（**必须先完成 SW-101 巡线改 I²C，这 3 个脚才空得出来**）。

两个备注：
- **走线长度不必强求等长**：4kHz 以下，几厘米的线长差对相位影响可忽略；真正重要的是 4 只麦的**机械位置准确、共面、同朝向**。等长是好习惯，不是硬指标。
- **留一条后路**：本期按上表"4 只全接 GND"焊死（方案 a：每麦独立数据线）。若 M1 实测 ESP-IDF 多数据线采集不顺，可改方案 (b)：把其中一对麦的 L/R 从 GND 改接 3.3V（一只选左声道、一只选右声道），两只共享一根 SD 线——**硬件不用重焊，改两根跳线即可**。

> **新手名词：什么是"星型共地"？**
> **共地**：所有设备的负极（GND）最终要连到一起，电流才能循环——像条条河流汇入大海。
> **星型共地**：每个麦克风的 GND 各拉一根线，回到板上**同一个"总地"点**——像自行车辐条都汇到车轴；而不是像糖葫芦那样一个接一个串着接（那叫"链式/菊花链"）。
> **为什么要讲究**：电流流过导线会产生一点点电压降。链式接法时，后面麦的地电位会被前面麦的电流"垫高"，几路麦互相污染；星型让 4 路地线等长、独立回到中心点，4 个麦"地位平等"。DOA 要比较 4 路信号相差几微秒的先后，地线干净一点，定向就稳一点。
> **板上怎么做**：在电源入口附近留一个"总地"焊点，4 个麦的 GND 各用一根等长跳线焊过去；板小走不开线时，拉一排孔当"地排"就近连接（近似星型，也比串成一条支路好）。
> **怎么验证**：万用表蜂鸣档，任意两个麦的 GND 焊点之间应该"通"（响一下即通）。

## 5. 焊接步骤（洞洞板，零基础可跟）

1. **摆位**：板上按 4.5cm 边长画个正方形，4 只模块摆在四个角，**收音孔全部朝同一个方向**（朝上）；模块底部用硅胶柱垫高 2–3mm（进声孔别被板面贴死）。
2. **电源总线**：拉一条 3.3V 母线、一条 GND 母线过板子中心；4 个 VDD 用短跳线接到 3.3V 母线，4 个 GND 接到 GND 母线（星型）。每个 VDD 脚旁并一个 104 电容（可选）。
3. **时钟并联**：4 个 SCK 拧/焊到一根线上，汇总后出一根线（接 GPIO5）；4 个 WS 同样处理（接 GPIO4）。
4. **数据独立**：每只模块的 SD 各焊一根线，4 根一起出到一排排针，标记清楚顺序（SD1=原麦=GPIO6，SD2/3/4=GPIO38/39/40）。
5. **L/R**：4 个 L/R 脚全部焊到 GND 母线。
6. **通断检查（必须做）**：万用表蜂鸣档——3.3V 母线对 GND 母线**不应通**；抽点测 SCK/WS 并联正确（任意两个模块的 SCK 脚之间应通）。

> 焊锡丝用 0.5–0.8mm 细丝，模块焊点小，烙铁 300–350℃，每个点 1–2 秒即可，烫久了 INMP441 会坏。

## 6. 上电检查（对应最终方案 T3）

不装到狗上，先裸板验证：

1. ESP32 只接阵列电源和 6 根线（GPIO4/5/6/38/39/40），串口接电脑；
2. 烧录带 4 麦采集的测试固件（SW-102），播放测试音或拍手；
3. 看 4 路波形：**幅度差 <20% 即通过**（T3 标准）；
4. 常见故障对照：
   - **某一路完全没反应** → 查该模块 SD 虚焊、L/R 悬空、模块损坏；
   - **4 路都有声但幅度差大** → INMP441 个体灵敏度有差异（±3dB 正常）；差太多查朝向/被遮挡/虚焊；
   - **4 路都是噪声无语音** → SCK/WS 没并联好或 GPIO 号写错；
   - **某路时钟沿对不上** → 检查该模块是否混用了不同的 SCK 来源。

## 7. 减振与安装（自噪抑制第一道防线，别跳过）

1. 阵列板通过**硅胶柱/海绵**与狗体连接，**绝不与电机、壳体刚性接触**——电机振动会沿结构传进麦克风，比空气噪声更难搞；
2. 阵列板远离电机线、电池线（>2cm；必须交叉时垂直过）；
3. 阵列平面保持水平；外壳给阵列区开孔，别罩住；
4. 安装完后用最终方案 §6.1 T3 + SW-104（行驶中 DOA 可用性）复核——**边走边听**的效果在这一步才见分晓。

## 附录 A · 名词速查（小白版）

| 名词 | 大白话 |
|---|---|
| 共地 / GND | 公共负极：所有设备的负极最终连到一起，电流才能循环 |
| 星型共地 | 每个设备的 GND 各拉一根线回同一个中心点；本方案地线推荐这样接 |
| 链式 / 菊花链 | 一个接一个串着接；地线不推荐这样接（会互相污染） |
| 并联 | 多个脚焊到同一根线上（如 4 个 SCK 全接一起） |
| 独立走线 | 每个信号各走各的线、不并联（如 4 根 SD） |
| 母线 | 板上拉的一条公共走线（3.3V 母线、GND 母线） |
| 排针 | 一排金属针，把板的信号引出来插杜邦线 |
| SD / SCK / WS | 麦克风的三根线：数据 / 位时钟 / 字选择（切左右声道） |
| L/R | 选左/右声道的脚；本方案 4 只全接 GND（全选左声道） |
| 104 电容 | 0.1µF 小电容，并在电源脚旁滤掉高频杂波（可选） |
| 硅胶柱 | 减振小垫柱，让阵列板和狗体不刚性接触 |
| 通断检查 | 万用表蜂鸣档测两点通不通；"通"= 响一下 |
